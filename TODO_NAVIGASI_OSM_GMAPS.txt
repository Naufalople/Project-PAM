================================================================================
      DAFTAR PERBAIKAN: LBS REAL-TIME OSM & NAVIGASI EKSTERNAL (GMAPS)
================================================================================

Tolong perbaiki implementasi peta dan lokasi LBS pada proyek Flutter saya:

--------------------------------------------------------------------------------
1. INTEGRASI PETA INTERAKTIF OPENSTREETMAP (flutter_map)
--------------------------------------------------------------------------------
- Target File: Halaman Peta / LBS Titik Temu COD
- Instruksi:
  1. Gunakan library `flutter_map` dengan URL standar OSM: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`.
  2. Pastikan peta interaktif (bisa di-pan dan zoom) menggunakan `MapController`.

--------------------------------------------------------------------------------
2. LIVE LOCATION TRACKING REAL-TIME (Geolocator Stream)
--------------------------------------------------------------------------------
- Target File: State / Controller Halaman Peta
- Instruksi:
  1. DILARANG menggunakan `Geolocator.getCurrentPosition()` yang statis.
  2. Gunakan `Geolocator.getPositionStream()` untuk mendengarkan perubahan koordinat secara real-time.
  3. Setiap ada koordinat baru, perbarui posisi marker pengguna (`currentLocationMarker`) di peta tanpa membuat aplikasi lag. Jangan paksa kamera untuk selalu auto-center jika pengguna sedang menggeser peta.
  4. Batalkan langganan stream (`cancel()`) pada method `dispose()`.

--------------------------------------------------------------------------------
3. MARKER TITIK TEMU COD & PERHITUNGAN JARAK
--------------------------------------------------------------------------------
- Target File: UI Layer Marker
- Instruksi:
  1. Peta HANYA menampilkan 2 marker:
     - Marker A: Lokasi real-time pengguna.
     - Marker B: Titik lokasi COD/Serah Terima yang sudah dipilih sebelumnya.
  2. DILARANG menggambar garis polyline atau rute jalan apapun di atas peta.
  3. Hitung jarak lurus (menggunakan `Geolocator.distanceBetween`) dari lokasi pengguna ke titik COD, lalu tampilkan teks jarak tersebut di UI (misal: "Jarak ke titik temu: 2.5 km").

--------------------------------------------------------------------------------
4. TOMBOL ARAHKAN DENGAN GOOGLE MAPS (NAVIGASI EKSTERNAL)
--------------------------------------------------------------------------------
- Target File: Tombol Aksi di Halaman Peta
- Instruksi:
  1. Buat tombol besar di bagian bawah peta bertuliskan "Arahkan dengan Google Maps".
  2. Gunakan package `url_launcher` untuk membuka URI intent peta eksternal ketika tombol ditekan.
  3. Format URL yang digunakan: `https://www.google.com/maps/dir/?api=1&origin={lat_user},{lng_user}&destination={lat_cod},{lng_cod}`.
