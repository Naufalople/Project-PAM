================================================================================
          DAFTAR PERBAIKAN LBS MAPS, KONTEKS LLM, & UI OVERFLOW
================================================================================

Tolong perbaiki dan implementasikan 3 poin perbaikan berikut pada codebase secara hati-hati tanpa mengubah fungsi utamanya:

--------------------------------------------------------------------------------
1. PENYESUAIAN PETA LBS COD & NAVIGASI EKSTERNAL (GMAPS)
--------------------------------------------------------------------------------
- Target File: Halaman Peta LBS / Titik Temu COD
- Masalah: Navigasi rute internal dan teks panduan jalan di dalam aplikasi terlalu berat/kompleks.
- Instruksi:
  1. Hapus fitur panduan rute jalan (turn-by-turn) dan garis rute navigasi dari dalam aplikasi.
  2. Pertahankan fungsi perhitungan jarak antara lokasi GPS HP saat ini ke lokasi titik temu COD.
  3. Tampilkan widget peta (Map) yang interaktif (bisa digeser/zoom) yang hanya memunculkan 2 titik marker: Pin lokasi saat ini dan Pin lokasi COD.
  4. Buat tombol "Arahkan dengan Google Maps" yang ketika ditekan akan melempar (menggunakan package `url_launcher`) titik koordinat tujuan ke aplikasi eksternal seperti Google Maps untuk navigasi sesungguhnya.

--------------------------------------------------------------------------------
2. PERLUASAN KONTEKS CHATBOT LLM (MEMBACA DATA KATALOG)
--------------------------------------------------------------------------------
- Target File: Modul LLM / layanan_ai.dart / halaman_chatbot.dart
- Masalah: Chatbot belum bisa menjawab spesifikasi barang yang ada di dalam aplikasi (misal: barang termahal/termurah).
- Instruksi:
  1. Perluas system prompt (batasan AI) agar mengizinkan chatbot merespons pertanyaan terkait isi data aplikasi.
  2. Suntikkan (inject) ringkasan data katalog produk (nama barang dan harga) ke dalam konteks AI saat pengguna bertanya.
  3. Pastikan AI mampu memproses data tersebut sehingga dapat menjawab akurat jika pengguna bertanya, "Apa barang termahal atau termurah di aplikasi ini?".

--------------------------------------------------------------------------------
3. PERBAIKAN BUG UI: BOTTOM OVERFLOWED PIXELS
--------------------------------------------------------------------------------
- Target File: Halaman Pelacakan Pesanan dan halaman lain yang terdampak overflow
- Masalah: Terjadi error garis kuning/hitam "Bottom Overflowed by X pixels" di banyak halaman, terutama di Pelacakan Pesanan.
- Instruksi:
  1. Lakukan audit pada widget tree di halaman Pelacakan Pesanan dan halaman lainnya yang rentan terhadap overflow.
  2. Bungkus Column atau widget yang memanjang ke bawah dengan `SingleChildScrollView` agar konten bisa di-scroll.
  3. Gunakan `Expanded` atau `Flexible` dengan benar pada widget anak di dalam `Column`/`Row` untuk mencegah layout menabrak batas layar.
  4. SANGAT PENTING: Lakukan perbaikan layout visual ini TANPA mengubah, menghapus, atau merusak fitur dan logika fungsional yang sudah berjalan.
================================================================================
