================================================================================
       DAFTAR PERBAIKAN: INTEGRASI SUPABASE & NAVIGASI LBS INTERNAL
================================================================================

Tolong implementasikan dua perubahan utama berikut pada codebase aplikasi:

--------------------------------------------------------------------------------
1. INTEGRASI SUPABASE UNTUK SINKRONISASI PESANAN REAL-TIME
--------------------------------------------------------------------------------
- Target File: Layanan Database, Layanan Pesanan, dan State Management
- Instruksi:
  1. Gunakan Supabase sebagai database online utama untuk menggantikan penyimpanan lokal.
  2. Buat alur sinkronisasi dua arah (two-way sync) secara real-time.
  3. Sisi Traveler: Saat Pemesan membuat pesanan baru, data tersebut harus langsung muncul di perangkat Traveler secara online.
  4. Sisi Pemesan: Saat Traveler mengonfirmasi pesanan atau memperbarui status pengiriman, perubahan status tersebut harus langsung ter-update di layar Pemesan secara real-time.

--------------------------------------------------------------------------------
2. PENGEMBALIAN FITUR NAVIGASI LBS KE DALAM APLIKASI (IN-APP ROUTING)
--------------------------------------------------------------------------------
- Target File: Halaman Peta / LBS Titik Temu COD
- Instruksi:
  1. Batalkan pelemparan rute ke Google Maps eksternal. Aplikasi harus bisa melakukan navigasi secara mandiri di dalam aplikasi itu sendiri.
  2. Implementasikan API perutean (misalnya OSRM) untuk menggambar garis panduan rute pada peta OSM dari lokasi GPS pengguna saat ini menuju titik COD.
  3. Pastikan rute/navigasi tersebut bergerak dan mengarahkan pengguna langsung di layar aplikasi.
================================================================================
